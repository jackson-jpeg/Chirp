Open Source Credits

ChirpChirps is built with the help of these open source libraries.

Opus (swift-opus)

High-quality, low-latency audio codec for push-to-talk voice communication.

License: BSD 3-Clause

github.com/alta/swift-opus

GRDB.swift

SQLite toolkit for Swift. Local encrypted message storage and persistence.

License: MIT

github.com/groue/GRDB.swift

MapLibre Native

Open source map rendering engine for offline peer location maps.

License: BSD 2-Clause

github.com/maplibre/maplibre-gl-native-distribution

OpenFreeMap

Free map tile service for offline map downloads. No API key, no tracking.

License: Open Data

openfreemap.org

Apple Frameworks

  • MultipeerConnectivity — peer-to-peer mesh networking
  • CoreBluetooth — BLE device discovery
  • NearbyInteraction — Ultra-Wideband precision ranging
  • Speech — on-device speech recognition for translation
  • Translation — on-device language translation
  • CryptoKit — AES-256-GCM encryption and Ed25519 signatures
  • CoreMotion — dead reckoning navigation
  • SoundAnalysis — environmental audio classification
  • AVFoundation — audio capture and playback

We are grateful to the open source community for making these tools available.
