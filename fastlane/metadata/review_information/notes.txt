ChirpChirps has no accounts, no sign-in and no servers. It connects nearby devices directly over Bluetooth and peer-to-peer Wi-Fi (Apple's MultipeerConnectivity), so nothing a user shares ever leaves the devices around them.

TESTING EVERY FEATURE ON ONE DEVICE (2.1)
Open Settings > Demo Mode, or tap "Try Demo Mode" on any empty screen (Talk, Messages, a chat, or the Map). Demo Mode adds simulated nearby users with existing chats, voice messages, map positions and push-to-talk replies:
1. Four simulated people appear, counted in the peer count, and the header stops reading "No mesh".
2. Three channels (General, Trailhead, Basecamp) arrive with message history, delivery and read receipts, and received voice messages that play.
3. Sending a text is acknowledged and answered.
4. Hold the talk button, let go, and a simulated person answers a few seconds later with audio you can hear.
5. The Map shows their pins near your position, or near a default position if location is off. Check In works.
6. Voice Messages and Settings are fully functional.
A "DEMO" badge sits on every screen with a one tap exit, the setting persists until it is switched off, and it is off by default. Demo traffic is generated on the device and blocked at the transport layer, so nothing is transmitted while Demo Mode is on.

PERMISSIONS (5.1.1)
Microphone: requested at the end of onboarding. The last onboarding screen explains push-to-talk and its only button is Continue, which shows the iOS prompt. Whatever the answer, the app opens and works. If access is off, the Talk screen shows a short notice with an Open Settings button.
Location: requested only when the user taps Check In on the Map. The explanation that appears has one button, Continue, which shows the iOS prompt, and it cannot be swiped away. Sharing lasts 15 minutes, stops on its own, and there is no automatic or background check-in. Declining leaves everything else working, and the Map shows the same short notice with Open Settings.
No permission is requested at launch, and no screen that precedes a permission request offers any way onward except the request itself.

TESTING THE MESH WITH TWO DEVICES (optional)
Install on two devices in proximity and launch both; they find each other within seconds. A single device with Demo Mode off shows "No mesh", which is expected rather than a malfunction. The Simulator has no Bluetooth, so real mesh testing needs hardware. Demo Mode covers every feature on one device.

Age rating is 18+. The privacy policy is at https://chirpchirps.com/privacy. Blocking is available from any message bubble, peer bubble or map pin, and Settings > Blocked Users lists and unblocks.
